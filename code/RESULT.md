## Comando de Execução

```
/usr/bin/env /Users/marcos/.vscode/extensions/redhat.java-1.54.0-darwin-arm64/jre/21.0.10-macosx-aarch64/bin/java \
  -XX:+ShowCodeDetailsInExceptionMessages \
  -cp /Users/marcos/Developer/tp2-fpaa-tango-solver/code/target/classes \
  tp2.fpaa.Main
```

### Flags utilizadas

| Flag                                    | Categoria  | Efeito                                                                                      |
|-----------------------------------------|------------|---------------------------------------------------------------------------------------------|
| `-XX:+ShowCodeDetailsInExceptionMessages` | Diagnóstico | Inclui o nome da variável/campo nulo em `NullPointerException` (ex: `Cannot read field "x" because "obj" is null`) |
| `-cp <path>`                            | Classpath  | Aponta para o diretório de classes compiladas pelo Maven (`target/classes`)                 |

> **Nota sobre warm-up da JVM:** nenhuma flag de aquecimento (`-Xcomp`, `-XX:+TieredCompilation`, etc.) foi usada. O JIT opera no modo padrão, o que pode elevar ligeiramente os tempos dos primeiros boards executados (4×4, 6×6-easy) antes do compilador nativo otimizar o bytecode.
